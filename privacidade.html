Política de Privacidade

Como tratamos os dados pessoais quando contactas a MXCross.pt.

2. Dados que podem ser tratados

Quando contactas a MXCross.pt por WhatsApp, e-mail, redes sociais ou através do pedido de orçamento, podem ser tratados dados como nome, contacto, marca e modelo do veículo, fotografias, medidas e a informação que escolhas enviar sobre o serviço pretendido.

3. Finalidades

Os dados são utilizados para responder a pedidos de informação, preparar orçamentos, organizar marcações, prestar os serviços solicitados e manter comunicações relacionadas com o trabalho pedido.

4. Pedido de orçamento e WhatsApp

O formulário de orçamento deste site não envia os dados para uma base de dados própria: organiza a mensagem e abre o WhatsApp para que o utilizador decida enviá-la. A partir desse momento, o tratamento efetuado pelo WhatsApp/Meta fica também sujeito às respetivas políticas e termos.

5. Assistente do site

O assistente atualmente disponível no site funciona através de respostas automáticas no próprio navegador. O código atual não envia as mensagens escritas no chat para uma base de dados da MXCross.pt.

6. Fundamento e conservação

Os dados são tratados na medida necessária para responder ao pedido do utilizador, diligências pré-contratuais, execução de serviços e cumprimento de obrigações legais aplicáveis. São conservados apenas durante o período necessário para essas finalidades ou pelos prazos exigidos por lei.

7. Direitos do titular

Nos termos da legislação de proteção de dados aplicável, podes solicitar acesso, retificação, apagamento, limitação, oposição ou portabilidade dos teus dados, quando aplicável. Para exercer estes direitos, contacta comercial@mxcross.pt.

8. Reclamações sobre dados pessoais

Sem prejuízo de outros meios de recurso, o titular pode apresentar reclamação junto da Comissão Nacional de Proteção de Dados (CNPD).

9. Cookies e serviços de terceiros

A versão atual do site não utiliza ferramentas próprias de publicidade comportamental ou análise estatística. Links para WhatsApp, Facebook, Instagram e outros serviços externos podem ficar sujeitos às políticas de privacidade desses terceiros.

10. Alterações

Esta política pode ser atualizada sempre que o funcionamento do site, os serviços ou as obrigações legais se alterem.
